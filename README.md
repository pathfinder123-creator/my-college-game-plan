# My College Game Plan

Set Goals. Create a Strategy. Build Your Skills.

## Publish in a new GitHub repository

1. Create a repository (for example, `my-college-game-plan`).
2. Upload the contents of this folder to the repository root. Keep `index.html` at the root; do not upload the enclosing folder or ZIP.
3. In Settings > Pages, choose Deploy from a branch, select your branch (usually main), and select / (root). Save.
4. Open the Pages URL once GitHub finishes deployment.

Upload index.html, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png, and apple-touch-icon.png. README.md is optional.

## Student navigation

Next and Back follow Career 1 > Program 1 > Career 2 > Program 2 > Career 3 > Program 3 > Career 4. Clicking a major tab opens its first stage. Numbered selectors allow direct access. Career 4 has no Next button.

## Install and saved information

On a supported desktop browser, use the address-bar install option or browser menu. On iPhone/iPad, use Safari Share > Add to Home Screen. On Android, use the browser menu Install app / Add to Home screen.

Information saves in this browser on this device. This version uses its own saved-data key, separate from My College Pathway. To carry an existing plan over, export it from the earlier tool and import it here. Import replaces the current saved plan after confirmation.

After one successful online visit, the app shell can load offline. External tools and college links require internet access. Calendar downloads create .ics files; they do not automatically add events or send notifications.

For later updates, increment the cache version in sw.js and upload changed files. The app updates online; reopening it can help refresh an installed copy.
